# Cortado e Servido · site do aplicativo

Site público do canal Cortado e Servido, usado no cadastro do aplicativo nas plataformas (TikTok for Developers).

- Endereço: https://joaoppk2.github.io/cortadoeservido/

Publicado pelo GitHub Pages a partir do branch `main` (pasta raiz). **Não mudar o endereço nem renomear o
repositório**: ele está cadastrado na auditoria do app do TikTok.

## Arquivos

| Arquivo | O que é |
|---|---|
| `index.html` | página inicial do canal |
| `tiktok.html` | página do app no TikTok |
| `privacidade.html`, `termos.html` | política de privacidade e termos de uso |
| `tiktok-privacidade.html`, `tiktok-termos.html` | as mesmas, nos endereços informados ao TikTok |
| `callback.html` | volta do login do TikTok |
| `tiktok*.txt` | arquivos de verificação do domínio pelo TikTok: **não apagar** |
| `style.css`, ícones | estilo e ícone do app (o mesmo da auditoria) |

O site do Painel (portfólio e vendas) fica no repositório `painel-cortadoeservido`, e o código do canal no
repositório privado `youtube-shorts`.
